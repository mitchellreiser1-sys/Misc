# south_central — nursing home administrator research notes (TX, OK, LA, AR, MS)

Pulled 2026-10-30. Deliverable: `administrators.csv` in this directory (one row per state-listed nursing
facility; `ccn` blank where no confident match to the CMS key). Per-state intermediate files:
`tx_admins.csv`, `ok_admins.csv`, `la_admins.csv`, `ar_admins.csv`, `ms_admins.csv`.
Scripts: `scripts/` (matchlib.py = shared matcher; one `<st>_process*.py` per state; `pw_fetch.js`,
`ar_list.js`, `ar_pages.js` = Playwright fetchers; `ms_plumb.py` = pdfplumber table extraction).
Raw downloads: `downloads/<st>/`.

Matching approach (all states): a state record is matched to the key by (1) the state's own CMS/Medicare
number when published (`ccn_direct`, Texas only), else (2) normalized house-number + street token within
the same ZIP (`address`), else (3) 10-digit facility phone (`phone`), else (4) token-overlap name
similarity within ZIP (`name_zip`) or city (`name_city`). A CCN already claimed by a stronger match is
excluded from later fuzzy matches, so no CCN appears twice. Confidence: `high` = direct/unique
address/phone+name agreement; `medium` = unique phone or name similarity 0.5–0.7; `low` = name-only
0.34–0.5 (only 0–2 rows per state; review before use).

## Texas (TX)

- **Source:** Texas HHSC, "Directory of Nursing Facilities with an Active License as of 10/28/2026"
  (Excel). Linked from https://www.hhs.texas.gov/providers/long-term-care-providers/nursing-facilities-nf
  ("Directory of all Texas nursing facilities").
- **URL (re-pull):** `curl -L -A "Mozilla/5.0" https://apps.hhs.texas.gov/providers/directories/NF.xlsx`
  (the apps.hhs.texas.gov host accepts plain curl; www.hhs.texas.gov returns 403 to non-browser clients).
  Companion files: `.../directories/HospNF.xlsx` (hospital-based NFs — **no administrator column**),
  `.../directories/Closures/nf_closures.xlsx`.
- **As-of date:** 2026-10-28 (stated in the sheet title). File is regenerated by HHSC regularly.
- **Fields used:** Facility Name, Physical Address/City/Zip, Facility Phone Number, License No,
  Medicare Provider Number (= CCN), Administrator, Provider Email (facility contact email, not
  necessarily the administrator's).
- **Counts:** 1,175 licensed NFs in source, all 1,175 carry an administrator name. 1,169 matched to a CCN
  (1,150 by Medicare number directly, 19 by address where the Medicare number was blank/different).
  Key coverage 1,169 / 1,177 (99.3%).
- **Gaps:** 6 source facilities are licensed-only (not certified) and have no CCN (e.g., John Knox
  Village Medical Center, Presbyterian Manor, Iowa Park Healthcare Center). 8 key CCNs not covered:
  5 hospital-based SNF units (455069 Baylor Scott & White Continuing Care, 455683 Hendrick SNF,
  455770 OakBend, 675268 Laredo Medical Center, 675370 Methodist Hospital SNF, 745052 HCA Houston SE)
  which appear only in HospNF.xlsx without an administrator field; 675080 The Vosswood Nursing Center
  and 675834 Brookdale Galleria are not in the active-license directory (likely closed/relicensed).
- **Notes:** Administrator names are as published (upper case, sometimes with middle initial). Two
  names carried a stray trailing digit in the source ("GILBERT MARTINEZ1") which was stripped.
  The old LTC Provider Search (apps.hhs.texas.gov/LTCSearch) is gone ("File Not Found"); the Texas
  Open Data Portal (data.texas.gov) has no nursing facility dataset — the directory Excel is the
  authoritative public list.

## Oklahoma (OK)

  https://oklahoma.gov/health/services/licensing-inspections/long-term-care-service/health-facility-systems.html
  (section "Directory of Facilities" → Box Folder). Files used: `NursingHomes_20261008_Updtd.pdf`
  (287 facilities incl. continuum-of-care "CC" nursing units), `NursingHomesLicOnly_20261002.pdf` (1),
  `VeteransNF_20261002.pdf` (7). Each PDF has columns Facility ID, Name, Address, City/ST/ZIP,
  Telephone, Administrator, Licensed Beds, County.
- **URL (re-pull):** Box share https://healthokgov.box.com/s/1sdgq0x18h399vyduxw4rwzqh1ox3h1i.
  Direct download pattern (file ids change when OSDH re-uploads; list the folder page and grep
  `"typedID":"f_<id>"` next to the file name):
  `https://healthokgov.app.box.com/index.php?rm=box_download_shared_file&shared_name=1sdgq0x18h399vyduxw4rwzqh1ox3h1i&file_id=f_2516346987653`
  (NursingHomes), `f_2516341597427` (LicOnly), `f_2516334234317` (Veterans). Then `pdftotext -layout`
  and `scripts/ok_process.py`.
- **As-of date:** 2026-10-02 (printed footer on all three PDFs; file name says updated 2026-10-08).
- **Counts:** 295 facilities parsed, 294 with an administrator (one shows "No Admin" → left blank).
  283 matched (278 by address, 5 by phone). Key coverage 283 / 283 (100%).
- **Gaps:** 12 unmatched rows = 7 state Veterans Centers (state-run, not in the CMS key), 1

## Louisiana (LA)

- **Source:** Louisiana Department of Health, Health Standards Section, "Licensed Providers Report"
  (monthly Excel), filtered to PROGRAM_DESCRIPTION = "Nursing Home". Page:
  https://ldh.la.gov/page/3008 (HSS Provider Directories). Fields: facility name, geographic address,
  parish, STATE_ID, LICENSURE_NUM, licensure dates, ADMINISTRATOR, EMAIL_ADDRESS, telephone, fax.
- **URL (re-pull):** https://ldh.la.gov/assets/hss/DirectorySpreadsheets/Licensed_Providers_Report_YYYY_MM.xlsx
  (used `Licensed_Providers_Report_2026_10.xlsx`; posted by the 5th of each month, reflecting prior
  month changes). The companion `Certified_Providers_Report_2026_10.xlsx` has ADMIN FIRST/LAST NAME but
  contains no nursing-home program rows, so it was not used.
- **As-of date:** 2026-10-05 (October 2026 report; LDH posts "by the 5th of the month").
- **Counts:** 266 licensed nursing homes, all with an administrator; 264 matched (253 address, 11 phone).
  Key coverage 264 / 265 (99.6%).
- **Gaps:** Unmatched: Poydras Home and St. Anna's at Lambeth House (New Orleans) — licensed but not
  Medicare/Medicaid certified. Key CCN 195622 Willis-Knighton Extended Care Center (Shreveport) is not
  a separately licensed nursing home (hospital-based unit under the hospital license) and is not in the
  report.
- **Notes:** EMAIL_ADDRESS is the facility's licensure contact email (often the administrator's, but
  not guaranteed). LICENSURE_NUM is given as `state_license_number`.

## Arkansas (AR)

- **Source:** Arkansas DHS, Division of Provider Services & Quality Assurance / Office of Long Term
  Care — "Long Term Care Facilities" profile pages on humanservices.arkansas.gov (WordPress post type
  `facilities`, one page per licensed LTC facility, with Administrator, Administrator License No.,
  address, phone, beds, Classification, ownership). Found via the Freedom of Choice list
  (https://humanservices.arkansas.gov/divisions-shared-services/provider-services-quality-assurance/information-about-our-licensed-providers/freedom-of-choices/).
- **URL (re-pull):** The host returns 403 to curl/non-browser clients, so a headless browser is
  required (Playwright). Steps: (1) `node scripts/ar_list.js <outdir>` pages through
  `https://humanservices.arkansas.gov/wp-json/wp/v2/facilities?per_page=100&page=N&_fields=id,title,link,slug,modified`
  (508 facilities of all LTC types); (2) `node scripts/ar_pages.js facilities_list.json pages` fetches
  each facility page (2 s pause, 45 s back-off on HTTP 429 — the site rate-limits at ~1 req/s);
  (3) `python3 -I scripts/ar_process.py pages ar_admins.csv <date>` parses the "Key:-Value" lines and
  keeps classifications containing NF / SNF / Nursing Facility (plus unclassified pages that match a
  certified facility by address/phone).
- **As-of date:** no global as-of; each page has a WordPress `modified` timestamp (kept in the crawl
  files). `source_date` = pull date 2026-10-30.
- **Counts:** 508 facility pages crawled (all LTC types; 0 fetch errors after retries). 243 pages have a
  nursing-facility classification (SNF dual-certified / Nursing Facility / NF-SNF variants, incl. 2
  unclassified pages matched by phone to certified NFs). 234 of the 243 carry an administrator name.
  221 matched to a CCN (210 by address, 11 by phone). Key coverage 221 / 222 (99.5%).
- **Gaps:** 22 NF-classified pages did not match a key CCN; most look like stale or closed licenses
  (e.g., Dallas County Nursing Home, Zimmerman Nursing Home, Bensons, Forest Healthcare, Hospitality
  Care Center — several have no phone and no administrator on their page) or newer licensees not yet
  in the key (The Blossoms at Breckenridge/Oakdale/Star City, Promenade Health and Rehabilitation,
  Lexington Place, Parkway Health Center, StoneRidge). 9 rows have a blank administrator (8 unmatched
  pages plus Barnes Healthcare 045314, whose page shows no administrator). Key CCN 045482 Mill Creek
  Health and Rehab LLC (4682 S 48th St, Springdale) has no facility page under any name/address.
- **Notes:** `source_url` is the individual facility page. The page shows the administrator's state
  license number (recorded inside `source_name`). No email on the pages. The printable county reports
  and the Freedom of Choice search are JavaScript-driven views of the same records.

## Mississippi (MS)

- **Source:** Mississippi State Department of Health, Health Facilities Licensure and Certification,
  "Directory of Mississippi Health Facilities" (Health Facilities Directory PDF), section "Nursing Home
  Facilities" (pp. 47 ff.) — columns Provider Name, Title 18/19, Type, Capacity, Physical (Mailing)
  Address, City/State/Zip, County, Phone, Licensee, **Administrator**.
- **URL (re-pull):** The old msdh.ms.gov URLs (`/msdhsite/_static/resources/7660.pdf`,
  `/page/30,0,83,613.html`) now 404; MSDH moved to a new CMS. Use the site search API
  `https://msdh.ms.gov/api/search?q=health%20facilities%20directory` (needs a browser/JS-capable
  client; returns JSON with media URLs) → current file
  https://msdh-production-assets.s3.amazonaws.com/media/JP0bYuHZMrPmLhpTmqWRuoDiRbRlSIMSS6BsMzML.pdf
  (dated September 18, 2026; an April 29, 2026 edition is at
  `.../media/01KNVY3Z337ESKY9SV4MYWQM4E.pdf`). The S3 URL downloads with plain curl. Parse with
  `python3 -I scripts/ms_plumb.py <pdf> nh_records.json` (pdfplumber word positions, columns from the
  header, one block per "Type" cell) then `scripts/ms_process2.py nh_records.json ms_admins.csv 2026-09-18`.
- **As-of date:** 2026-09-18 (printed on every page).
- **Counts:** 210 nursing homes parsed (directory total line says 209; one entry appears twice as two
  licensed units), all with an administrator. 201 matched (135 address, 59 phone, 7 name+zip).
  Key coverage 201 / 202 (99.5%).
- **Gaps:** 9 unmatched = 5 MS State Veterans Homes (state-run, not in key), S.E. Lackey Convalescent
  Home, St. Catherine's Village–Siena Center, The Arbor (Ridgeland), Winston County Nursing Home —
  licensed but not in the CMS key. Key CCN 255096 Louisville Healthcare LLC (543 E Main, Louisville)
  is not in the directory under that name/address (Winston County Nursing Home is at 17560 E Main
  with a different phone, so it was not forced).
- **Notes:** MSDH's new facility locator (https://msdh.ms.gov/resources/facility-locator/health-facility-search,
  Inertia JSON embedded in the page) lists the same 210 nursing homes with name/address/phone/licensee
  but its `administrator` field is populated only for hospitals and ICF/IIDs, so the PDF directory is
  the administrator source. The MSDH "Nursing Home Search" app (apps.msdh.ms.gov/nursinghome) only
  serves survey PDFs. No state license numbers are printed for nursing homes.

## Blocked / caveats

- Sites that refuse non-browser clients: www.hhs.texas.gov (403; apps.hhs.texas.gov is fine),
  humanservices.arkansas.gov (403 to curl, 429 when fetched faster than ~1 page/2 s), msdh.ms.gov
  (JS app; old URLs 404). All were handled with Playwright (pre-installed chromium) or the S3/Box
  direct file links above; no bot-check circumvention beyond a normal headless browser was used.
- medicaid.ms.gov and healthyms.com fail TLS through the session proxy (unable to get local issuer);
  not needed in the end.
- No paid or non-public sources used. No names were inferred; blanks mean the state listed none.

# West region (agent "west") - nursing home administrator sources

States: CA, WA, OR, AZ, NV, UT, CO, NM, ID, MT, WY, HI, AK. Pull date for everything: 2026-10-30.
Deliverable: `administrators.csv` in this directory (one row per facility from each state source; `ccn` blank when
no confident match to `facility_key.csv`; `administrator_name` blank when the source publishes no name).
All raw downloads are under `downloads/<state>/`, all scripts under `scripts/` (run with `python3 -I`).
Matching (`scripts/common.py`): `ccn_direct` when the state source carries the CCN and it is in the key; otherwise
address (normalized street + same zip/city), phone (10-digit), name+zip, name+city. Confidence `high` for
ccn_direct/address/phone-with-name-agreement, `medium` for weaker name/phone matches.
